# osucatalog

Find and download exactly the osu! beatmaps you want.

This is the official public home of osucatalog. The hosted product is in
development. A small command-line client may be published here when the public
API is ready.

This repository intentionally contains only material released for public use.
The production service, catalog, data pipeline, ranking and labeling systems,
operations, website source, and internal tools are not distributed here.
